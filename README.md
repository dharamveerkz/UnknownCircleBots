# UnknownCircle

Multi-feature Telegram bot suite built with Python.

## Features

### 🛡️ Moderation Bot

- Warn users
- Ban users
- Mute users
- Group rules

### 🎮 Games Bot

- Guess Number
- Rock Paper Scissors
- Trivia
- Leaderboards

### 🤖 AI Bot

- Gemini AI chat
- Translation
- Facts
- Roast mode

### 🎲 Fun Bot

- Memes
- Jokes
- Quotes
- Fortune
- Dice
